# FluxServe Project Ethics and Contribution Guide

TokenSpeed is built as a performance-driven system project for open diffusion langauge models.

## Contribution Type

We intend this project as a lightweight codebase, where changed should fit the existing codebase style and do not introduce unnecessary complexity.
There are several ways you can contribute to the project:

- Identify and report any obvious issues or bugs
- Request to add new model and algorithm support
- Suggest or implement small and verifiable production-needed features
- Request or implement new performane optimizations
- Improve documentation, such as tooling and benchmarking guides

For larger features or architectural changes, we highly recommend starting with an RFC feature issue first before implementation.
